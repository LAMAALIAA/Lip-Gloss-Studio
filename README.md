# Lip Gloss Studio

A bilingual (English/Arabic) responsive browser game made with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a modern browser.

## Publish on GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the **root** of your repository.
2. Make sure the entry file is named exactly `index.html`.
3. In Settings → Pages, select Deploy from a branch, branch `main`, folder `/(root)`.
4. Commit changes and wait for deployment.

The language toggle is in the top-right area. Saved designs are stored locally in the same browser using localStorage.
